# Countdown

An IGCSE February/March 2027 revision tracker (Zone 4, India): past-paper library, calendar,
goals, targets and a quiz: daily recall cards from the revision notes for Physics, Chemistry, Biology and
Maths (0607), and a written-definitions section (Physics, Chemistry, Biology, Economics) that you mark yourself.
Plain HTML, CSS and JavaScript; runs offline and syncs between your devices.

Each friend creates an account with a name and password and logs in on any device;
every account keeps its own data.
